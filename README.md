## 🔥 Neden "TaskMaster Logic"?

Bu projeyi geliştirirken odak noktam sadece görsel değil, aynı zamanda sağlam bir kod mimarisiydi:

* **Logic Architecture:** JavaScript tarafında veriler dinamik olarak yönetilir, hafıza dostu bir yapı kullanılmıştır.
* **Zero-Div Policy:** HTML yapısında gereksiz `div` kullanımından kaçınılarak, tamamen **Semantik HTML5** (`main`, `section`, `header`, `footer`) tercih edilmiştir.
* **Cosmic UI:** Kullanıcıyı yormayan ama içine çeken, derinlik algısı yüksek bir "Dark Space" teması uygulandı.
* **Fluid Responsive:** Tek bir medya sorgusuyla değil, esnek bir ızgara sistemiyle tüm ekranlarda kusursuz uyum sağlar.
